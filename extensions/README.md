# MonoRail extensions

Extensions are modules and apps for MonoRail built in their own repositories.
The design and the full guide are in [docs/extensions.md](../docs/extensions.md).

| Path | What it is |
| --- | --- |
| [`hello-monorail/`](hello-monorail) | The starter extension and working sample. Copy it with `npx degit wojoe-444/MonoRail/extensions/hello-monorail my-extension` |
| [`../packages/extension-sdk/`](../packages/extension-sdk) | The SDK every extension carries in `monorail-sdk/` |
