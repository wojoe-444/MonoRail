# MonoRail extensions

Extensions are modules and apps for MonoRail built in their own repositories.
The full guide is in [docs/extensions](../docs/extensions/README.md).

| Path | What it is |
| --- | --- |
| [`hello-monorail/`](hello-monorail/README.md) | The starter extension and working sample. The README covers copying it, building `ui/` and loading it into MonoRail. |
| [`../packages/extension-sdk/`](../packages/extension-sdk) | The SDK every extension carries in `monorail-sdk/` |
