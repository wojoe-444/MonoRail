# Find anything with Ctrl+K

Press **Ctrl+K** on any page (or click the top search bar) to search everything
at once:

- **Pages**: every destination in the sidebar (Chat, Explore, Storage, etc.).
- **Catalog**: every entity type in the
  [MonoRail standard](../standard/README.md) — selecting one opens
  [Explore](data/explore.md) directly at that type.
- **Chats**: recent non-archived sessions from [Chat](agents/chat.md).
- **Settings**: every Settings page, card and option, matching the search box in
  [Settings](setup/README.md#finding-your-way-around-settings).
- **Wiki**: every wiki page (lists guides when empty).

Opening Ctrl+K from Settings starts on the Settings scope. To search inside git
repositories (code, commits, diffs), use GitHub+'s own
[code search](workspace/search-code.md).

## Browse the catalog

Before you type, the palette shows your five most recent picks and the catalog's
sections. Pick a section to browse its types by category, or type to filter.
Click the section badge (or press Backspace on an empty box) to step back.
**Open Explore** jumps straight to [Explore](data/explore.md).

## Keys

| Key | Action |
| --- | --- |
| `Ctrl+K` | Open or close |
| `Up` / `Down` | Move selection |
| `Enter` | Open selected result |
| `Tab` / `Shift+Tab` | Cycle scopes (All, Pages, Catalog, Chats, Settings, Wiki) |
| `Backspace` (empty box) | Leave section, then return to All |
| `Esc` | Close |

On a phone via [Remote access](setup/remote-access.md), tap the search button in
the top bar.

## What it keeps

Nothing leaves your computer and nothing is cached, except your last five opened
items in your [profile](glossary.md#profile) preferences
([private data stays local](private-data.md)).
