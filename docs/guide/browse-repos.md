# Browse your repos

**Workspace > GitHub+** is a GitHub-style browser for the git repositories
on your own computer: the code, the README, the history, branches and
comparisons, without opening a terminal. It only reads; it never changes your
files.

## Open a repository

Press **Open a repository** and pick a folder. GitHub+ remembers it on its home
page with its recent activity. Repositories that MonoRail itself keeps, like
your Jira+ projects, are listed there automatically.

## What you can see

- **Code**: folders and files, with the README shown below, and when each
  file last changed.
- **History** and **commits**: every change, with its diff.
- **Branches** and **Compare**: how far branches have moved apart, and the
  difference between any two.

## Local issues

The **Issues** tab keeps a to-do list inside the repository itself: create,
comment, close and reopen issues, written in Markdown. They live in git (so
backups carry them) but a normal push does not send them anywhere. If the
repository also lives on GitHub, a new issue can optionally be created there
too; that switch starts off every time.

## Your GitHub repositories

Once you add your GitHub account on **Connections**, GitHub+ also lists your
repositories on github.com, including team ones. You can clone one into a
folder you pick, or open it on github.com. Repositories you already have on
your computer get a small cloud mark instead.

## Linked tasks

The **Tasks** tab shows Jira+ tasks linked to the repository, and you can
link more from either side.

## Backups

The **Backups** tab copies a repository to a folder of your choice on a
schedule. See [backups and updates](backups-and-updates.md).
