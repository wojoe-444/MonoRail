# Welcome to MonoRail

MonoRail is a desktop app for living with AI agents. It sits next to the
agents you already use, like Claude Code and pi, and gives you one place to
see what they are doing, talk to them, keep an eye on what they cost, and
look after the work they produce.

It is not a cloud service. MonoRail runs on your computer, reads files that
are already on your computer, and keeps what it learns there too.

## What you can do with it

- **Talk to your agents.** **Chat** lists the conversations you have had
  with Claude Code and pi on this computer, and lets you carry on any of
  them or start a new one.
- **See your agents.** **Agents** shows the subagents and skills you have
  set up, each with a small mochi character so they are easy to tell apart.
- **Know what you are spending.** **Claude Stats** turns your local usage
  logs into charts: cost per day, per model and per million words written.
- **Look after your code.** **GitHub+** is a friendly browser for the git
  repositories on your computer, with local issues and scheduled backups.
  **Jira+** does the same for tasks.
- **Let agents help themselves.** **Agent access** lets an agent read what
  MonoRail knows, and, only with your OK, write a few things back.
- **Add your own pieces.** **Extensions** add pages and apps that other
  people (or you) build in their own repositories.

## How this wiki is organized

Every page is tagged with who it is written for:

- **For people**: plain-language guides. You don't need to read code to
  follow them. Start with these.
- **For agents**: dense reference for agents and developers, full of exact
  file names, settings and rules. Useful when you are building something, or
  when you point an agent at the docs.

Some pages are both. The switch at the top of the page list picks which ones
you see; it starts on **For people**.
