# Design system

Use the shadcn/ui primitives in `src/components/ui/` and the visual direction
of Bot Dashboard (`dashboard/web` in `wojoe-444/MC-Player`). The
[developer reference](README.md) covers related contracts. See
[Desktop shell](desktop-shell.md) for navigation and
[Appearance](../guide/setup/appearance.md) for the palette picker.

## Components and layout

- Use the owned shadcn primitives (`radix-ui`, `cva` and `cn()`) and borrow
  MUI's page composition conventions. Keep MUI out of the dependency list.
- Cards sit on a hairline ring (`ring-1 ring-foreground/10`) with a 10px
  base radius, restrained typography and subtle focus rings. Use
  `shadow-elevation-2/3` for raised surfaces such as dialogs and menus.
- Inter Variable ships locally. Code and tabular numbers use
  `font-mono` with Cascadia Mono and Consolas. Keep JetBrains Mono out of
  the app, SVGs and the extension theme.
- The floating scrollbar pill is defined app-wide in the base layer of
  `src/index.css`. Keep page styles and global `scrollbar-width` and
  `scrollbar-color` declarations from overriding the Chromium rules.
- Use the 8px grid. Page gutters are 24px (32px on large screens), card gaps
  24px and section spacing 32px. Use a centered container up to 1536px
  and responsive grids.
- The shell has a permanent 60px icon rail and a 40px top bar aligned with
  its brand header. Nav icons use hover and focus tooltips, active rows
  use sidebar primary tokens, and count badges use amber.
- Use `PageHeader` for an optional overline, a 24px semibold title,
  a one-line subtitle and right-aligned actions. Use `StatTile` for
  KPI labels, 30px tabular values, semantic deltas and optional sparklines.
- Use the shared [Save bar](../guide/setup/saving.md) for a draft form.
  Put `SaveBar` at the bottom, outside clipped containers. Report saved
  state only after the backend confirms the write. Dialogs keep their
  footer actions and immediate controls keep their current behavior.

## Palettes

`src/lib/palettes.ts` defines primary and neutral hue/chroma plus a sidebar
style. `tokens()` expands these to light and dark OKLCH CSS variables and
`src/index.css` maps them to Tailwind with `@theme inline`. `lib/theme.ts`
writes the chosen mode and palette to `<html>`. Use tokens in component
styles. The default scheme is Winter Village (`DEFAULT_PALETTE`) in light mode;
the values in CSS are Sand & Ink, a plain fallback for the first paint.
Change palette definitions in `palettes.ts`.

Use primary for major actions, active navigation and links, primary-soft
for tinted surfaces and highlight for secondary emphasis. Semantic hues
(success, warning, info, destructive) stay constant across palettes.
Use soft semantic variants for badges, status and small tiles. The
full-screen hub bar shares sidebar colors. The only palette picker is
`src/components/theme/ThemePicker.tsx` in Settings > Appearance.

Picture palettes use WebP generated by `npm run backdrops` from
`scripts/backdrops/`, with a pre-blurred version for the glass treatment.
Use the pre-blurred assets because live backdrop filters made scrolling lag.
Review new UI in light and dark and with a dark-sidebar palette such as
Indigo Ink. Sync the [extension theme](../extensions/page-api.md#theme) when
tokens change.

## Charts

Use the Recharts primitives in `src/components/charts/`. Assign
`--series-1..6` in fixed order and group additional series in Other. Rank
on the full dataset so filters preserve colors. Use one y-axis, a legend
for multiple series, a table view for each chart, bars at most 24px wide,
2px lines and one main figure per page. Series colors stay fixed across
palettes. See [Agent usage](agents.md#claude-stats) for a reference feature.
